# M24 GitHub Pages Audio Hub

## Files
- `index.html` — mobile-friendly audio hub
- `audio/` — five canonical M24 MP3 files

## Deployment
1. Create a GitHub repository, for example `m24-audio-hub`.
2. Upload `index.html` and the entire `audio` folder.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select the branch containing these files and the `/ (root)` folder.
5. Save and wait for GitHub Pages to publish.
6. Open the published HTTPS URL and test every player.

## QR destinations
For the pilot, use the Audio Hub URL for the main QR, or create track-specific URLs later if desired. Do not create QR codes until the final HTTPS URL is known.

## QA
Test on a phone using mobile data and school Wi-Fi. Confirm each A01–A05 player loads and plays.
